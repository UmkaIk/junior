# Laman — сайт магазина сухофруктов

Статический сайт без сборки: `dist/` выкладывается на Netlify как есть (`netlify.toml` → `publish = "dist"`).

## Что заполнить перед открытием заказов

Всё в начале `dist/assets/app.js`, в блоке `CONFIG`. Строки с пометкой «ЗАГЛУШКА» не настоящие:

- `whatsapp` — номер продавца. Пока там нули, кнопка не отправляет заказ, а показывает сообщение для копирования.
- `instagram` — ссылка. Пустая не показывается.
- `products[].packs` — фасовки и цены.
- `delivery.fee`, `delivery.freeFrom` — стоимость доставки и порог бесплатной.
- `payment` — способы оплаты.
- `draft: false` — убрать плашку «цены предварительные».

## Картинки

Положите в `dist/assets/`: `apricot.webp`, `dates.webp`, `fig.webp`, `prune.webp`, `raisin.webp`, `caucasus.webp`.
Пока их нет, сайт рисует заглушки-пакеты и горы из `caucasus.svg`.

Шрифт Lora (лицензия OFL) лежит локально в `dist/assets/fonts/`.
